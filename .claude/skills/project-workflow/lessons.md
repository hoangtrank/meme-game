# Bài học xuyên dự án

Researcher và red-team đọc file này ở đầu mỗi lần chạy. Mỗi mục là một loại rủi ro từng bị bỏ sót hoặc một cách làm đã chứng minh hiệu quả. Chỉ thêm vào đây sau post-mortem được khách hàng duyệt. Sao chép file này sang dự án khác bằng `scripts/install-workflow.sh`.

Định dạng mỗi mục: ngày, dự án, loại, bài học một câu, cách kiểm tra lần sau.
